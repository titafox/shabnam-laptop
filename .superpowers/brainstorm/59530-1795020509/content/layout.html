A · 任务栏式（像 Windows / ChromeOS）

底部一条任务栏：开始按钮、固定的常用应用、右侧时间和网络电量。壁纸上可以摆图标。点开始或按键盘上的开始键弹出菜单，直接打字搜索。最像"一台电脑"，用过 Windows 的人不用学。

B · Dock 式（像 macOS）

顶部一条细状态栏，底部居中一个浮动 Dock 放常用应用，最右边是"全部应用"。壁纸保持干净，不摆图标。全部应用点开后是全屏网格加搜索。观感最精致，壁纸最出效果。

C · 搜索启动式（键盘优先）

屏幕中间一个时钟、一个搜索框、一排常用应用。在桌面上直接打字就开始搜索，回车打开应用或网址。最简洁最快，但偏"极客"，不熟悉的人第一眼不知道其他应用在哪。

三种共同的限制

没有 root，桌面管不了其他应用的窗口。所以任务栏或 Dock 默认只在回到桌面时出现，打开应用后看到的仍是系统自带的返回、主页、最近任务键。如果你希望任务栏在应用里也一直显示，可以用已经授权的悬浮窗来做，这是个可选项，选完布局后再说。
